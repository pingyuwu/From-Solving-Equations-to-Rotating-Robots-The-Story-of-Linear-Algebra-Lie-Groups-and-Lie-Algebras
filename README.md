**一句话预告**
- 线性代数处理"平的、可以直接加减"的空间；
- 李群描述"弯的、连成一片的对称性"（比如所有可能的旋转）；
- 李代数则是把这个弯曲的对称空间在某一点拍平，好让我们重新用上线性代数。

  本文就按这个顺序：先看线性代数解决了什么问题、留下了什么短板；再看李群为什么被发明出来补这个短板；最后看李代数如何把两者缝合起来。每一步都会配上一个你能在纸上画出来的小例子。

**本文路线**
- 线性代数：平直世界的加减法
- 李群：弯曲世界里的对称性
- 李代数：把弯曲世界"拍平"的那把刀
- 三者并排：两张对比表、一张关系图与一个干净样本
- 应用现场：它们在真实世界各管哪一段
